文件操作集成测试使用临时目录执行生产代码生成的 shell 命令，不连接相机。
Windows 驱动事务与 GUI 测试包含在完整套件中；本轮的该部分为模拟接口测试。

运行方式：

```sh

```

需要完整桌面依赖才能运行 GUI 测试，见[安装器开发说明](../installer/README.md#开发与构建)。

### 找到并修复的问题

1. USB 写入中断会留下 `.installer-next` 文件。恢复和卸载曾只处理正式文件，
   暂存文件可能包含不完整的程序或 FTP 配置。现在合作停止服务后，清理明确列出的
   安装目标及备份槽暂存文件；不递归删除目录，不删除备份正文或其他应用文件。
2. 相机的异步内核日志可能插入命令回复，甚至在结束标记之前留下半截文本。
   现在随机 nonce 标记不要求位于行首，文件存在性查询提取唯一的明确答案；
   保留对回显伪完成和冲突答案的拒绝。
3. 一次性发送长命令时，相机交互终端会丢失输入字节；只拆成短行仍不足以避免队列拥塞。
   现在用短的、正确转义的赋值行在临时 shell 变量中组装，并在每行间读取回显，
   再在子 shell 执行一次，随后清除变量。
   不创建新的相机文件，不因超时自动重放写操作。

### 实机范围

现场记录确认了内核日志交错和长命令输入丢失；卸载曾在暂存清理阶段中止，
