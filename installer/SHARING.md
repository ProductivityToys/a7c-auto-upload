# 发布与分享

本批安装器为 `0.1.0-preview.27`，相机载荷为 `0.4.2-photos.15-preview`。提供 macOS arm64、Windows x64 和脚本三个包，使用同一相机载荷。JPEG／ARW 图片上传默认关闭，开启后与视频共用普通 FTP、进度显示、SD 回执与失败重试。

## 发给使用者

- Mac：发送 DMG，将 App 拖入「应用程序」后打开。
- Windows：发送完整 ZIP，解压后打开「A7C 自动上传.exe」，保留 `_internal` 目录。
- 命令行／AI：发送 scripts ZIP；Mac 双击「开始使用.command」，Windows 双击「开始使用.cmd」，或按 CLI 指南带参数运行。

同时提供同批 `SHA256SUMS`。桌面包的说明、恢复、反馈与第三方许可内置在「使用帮助」中；脚本包对应说明位于 `app` 目录。

用户需要配置相机家中 Wi-Fi，并准备普通 FTP 账号和已存在的上传目录。安装器不创建服务器账号，也不安装 NAS 接收程序或 Photos 索引服务。照片始终交给原厂 FTP 时，可关闭本程序图片开关；开启图片上传时，默认勾选「原厂 FTP 开启时，暂停本服务的照片上传」，原厂 FTP 关闭后再由本服务继续补传，视频不受影响。

## 验证范围

已验证第一代 Sony A7C / ILCE-7C 固件 2.00，其他固件未测试，安装器会检查实际接口兼容性。已测主机为 macOS 27.0.1 arm64、Windows 11 build 26200 x64；Linux 脚本没有完整实机验收。

既有 macOS／Windows CLI 卸载、全新安装、默认启动及 Windows 驱动准备／恢复记录保留。图片更新的实机结果、源码测试及最终成品检查分别记录在 `validation.json` 和发行清单 `distributions.json`，不要把主机单元测试等同于另一台相机的验收。

macOS 包为临时签名、尚未公证；Windows 包未签名。首次打开方式见 [安装说明](START_HERE.md)，卸载和单槽回退见 [恢复说明](RECOVERY.md)。

发行包不包含个人 FTP 配置、密码、相机备份、媒体、Sony 库或字体，也不安装无线调试入口。无线维护属于本次测试的独立 RAM 工具，不是正式服务的依赖。

反馈按 [FEEDBACK.md](FEEDBACK.md) 提供版本、现象与脱敏诊断记录；不要附密码、机身私有备份或完整研究目录。项目下载入口及可见性以 GitHub 仓库当前设置为准。
