# 从这里开始：A7C 自动上传试用

这是供熟悉设备恢复的用户试用的预览版，不是索尼官方软件，也不是固件更新器。
仅适配 **第一代 ILCE-7C、机身固件 2.00**；A7C II、A7CR 和 2.03 不在本包支持范围。
安装与撤销的具体步骤见[恢复与卸载](RECOVERY.md)。

本说明对应 `0.1.0-preview.12` / 相机载荷 `0.4.1-installer.7-preview`。
旧 `preview.11` 下载包保持原样，使用本批新包及摘要。验收范围见同包 `validation.json`。

先点「连接相机」，macOS 按系统提示授权后自动继续。连接成功后填写 FTP 并安装；
读取配置、测试及安装复用同一 USB 会话。密码只显示是否已保存，留空沿用，填写新值才替换。
已安装相机会显示版本，并在相机卡片提供「卸载相机服务」。
「使用帮助」提供说明，「更多」提供启动、恢复及驱动操作，「运行日志」可展开或复制。
安装完成后默认启动服务，核对上传初始化及显示模块；健康检查通过后拔掉 USB 即可使用。
若显示「服务未就绪」，先看日志或用「更多 → 启动上传服务」重试，不需要重复安装。
更换已加载的显示组件，或卸载后在同一次开机中立即重装时，按界面提示完整重启；普通首次安装不要求取电池。
健康检查不代替相机实际上传验收。新版复用近期目录、短暂源等待不触发网络退避，并取消补传间的固定等待。

## 1. 选包并保存

| 电脑 | 选择 | 已测范围 |
| --- | --- | --- |
| Apple Silicon Mac | `*-macos-arm64.dmg` | macOS 27.0.1；不提供 Intel Mac 原生包 |
| Windows x64 | `*-windows-x64.zip` | Windows 11 build 26200；构建、界面及离线自检通过，完整 USB 安装未验收 |
| 使用命令行 | `*-scripts.zip` | 需要 Python 3.11+；首次安装依赖需联网 |

macOS：打开DMG，将「A7C 自动上传.app」拖入「应用程序」，推出DMG后从应用程序打开。
Windows：完整解压后直接双击根目录「A7C 自动上传.exe」，保留旁边的_internal目录。
脚本包：Mac双击「开始使用.command」，Windows双击「开始使用.cmd」，Linux运行 `sh start.sh`，按数字选择操作。
桌面App自带Python和依赖，不用另装Python或执行脚本；App内「使用帮助」提供全部用户说明与版本验收。
保留DMG/ZIP下载包、同批 `SHA256SUMS` 和自己的FTP配置，方便恢复。

可在下载目录验证压缩包摘要，替换为实际文件名：

```sh
# macOS
shasum -a 256 a7c-installer-0.1.0-preview.12-macos-arm64.dmg
```

```powershell
# Windows PowerShell
Get-FileHash .\a7c-installer-0.1.0-preview.12-windows-x64.zip -Algorithm SHA256
```

结果应与发送者通过可信渠道提供的 `SHA256SUMS` 对应行相同。摘要能检查文件变化，不替代发布者签名。

Mac包尚未公证。核实来源与摘要后，首次打开若提示未验证开发者，可按
[Apple官方步骤](https://support.apple.com/en-us/102445)在“系统设置 → 隐私与安全”对这一个App选择“仍要打开”。
如果提示文件损坏或恶意内容，先停止并反馈，不关闭系统安全功能。Windows包未签名，若被组织策略阻止，请反馈，不更改全局安全策略。

## 2. 准备网络与 FTP

- NAS或其他服务器启用**普通FTP**，为相机创建仅限上传目录的专用账号。当前不支持SFTP、FTPS、IPv6或域名。
- 填写服务器在相机所在网络可达的IPv4；建议固定地址或DHCP地址保留。电脑、相机和FTP服务器之间不能有阻断访问的访客隔离。
- 先创建目录。这里填的是**FTP登录后看到的路径**，例如账号根目录 `/` 或 `/Camera`，不是NAS操作系统的 `/volume1/...` 路径。
- 账号需要列目录、上传、查询长度、改名及删除测试文件的权限。服务器应支持 `SIZE`、`MLSD`、`STOR`、`RNFR/RNTO` 和被动数据连接（EPSV或PASV）；防火墙放行相应被动端口。
- 用户名和路径仅接受可打印英文字符；密码可为UTF-8，但不能包含换行或控制字符。用户名最长128字符，路径400字符，密码255字节。
- 多台相机分别使用独立上传目录，不让它们同时写同一个文件命名空间。

普通FTP不加密。账号密码会保存在机身root私有文件中，不是硬件加密保险箱；不要使用管理员账号或把FTP暴露到公网。
安装器不会创建服务器账号、配置NAS防火墙，也不会安装NAS接收服务或Photos索引服务。

相机原厂菜单先配好家中Wi-Fi。本项目现有实测使用“FTP传输功能：开”“FTP省电：关”；
安装器不设置这两项，也不读取或复用原厂FTP密码。新用户的原厂联网条件尚需独立验收，不能把在这台相机上可用等同于所有首次配置均已验证。

## 3. 准备相机与 USB

1. 在机身菜单确认型号与固件2.00，备份卡内重要文件，使用电量充足的电池。
2. 停止录像，等存储卡灯熄灭；只连接这一台相机，使用可靠的数据线，避免连接中途断电。
3. 将USB连接模式设为“海量存储器”，开机连接电脑，确认相机显示USB连接界面。
4. 关闭照片导入、原厂更新器和占用相机卷的程序。安装器不会升级或降级固件。

Mac通常不需另装Sony驱动；点击「连接相机」后由系统窗口收集管理员授权。
Windows需先按下一节处理USB驱动；App会申请管理员权限。

### Windows首次驱动设置

App会请求管理员权限。从「更多」选择“准备 Windows 驱动”，或直接连接相机/安装/读取运行日志，工具会自动完成必要的驱动准备，无需另外安装Zadig。
它先核对普通USB设备报告的型号，再为普通接口配置驱动；相机切到服务模式后会自动处理服务接口。
「连接相机」会建立临时服务会话，并自动准备必要驱动；脚本detect仍仅枚举。

原驱动信息、原第三方驱动备份与恢复记录存于此电脑 `%ProgramData%/A7CInstaller/drivers`，不要删除。
更换驱动后资源管理器可能无法读取相机卷；需要恢复时点击“恢复普通 USB 导入”。
卸载相机服务默认勾选联动恢复电脑驱动；原本手工安装的驱动只复用，不自动删除。
若驱动被系统签名策略/组织策略阻止，保留提示并反馈，不关闭系统保护。
驱动自动化已完成离线验证，真实相机的普通/服务模式安装与恢复仍需要独立验收，详见[恢复说明](RECOVERY.md#windows驱动恢复)。

## 4. 安装

1. 打开App，点击「连接相机」。工具临时进入USB服务模式，读取本上传器配置并保持会话；实际安装前校验机型、固件及原厂接口。
2. 已有配置会自动填入地址、端口、账号及目录；密码框显示“已保存”，留空沿用，填写新值才替换。首次安装没有已保存密码时需要填写。配置字段始终可编辑。密码不会回填到界面，也不持久保存到电脑。
3. 点击「测试连接」。它从**当前电脑**上传小文件、查长度、改名并删除，不读取已有视频；成功不证明相机侧网络或MLSD兼容性。
4. 确认「在相机上显示上传状态和进度」选项，点击「安装到相机」或「更新配置」，保持连接直到明确显示完成。
5. 等服务健康检查通过，按提示拔掉USB，回到视频实时画面直接使用。不用例行关机或取电池；若加载中的显示模块有版本变化，再按具体提示处理。

若过程中中断、超时或显示“未完成”，不要直接再点安装；转到[中断恢复](RECOVERY.md#安装中断或想撤销最近一次变更)。
安装器不是恢复出厂工具，不能修复所有系统异常。

## 5. 第一次确认与日常使用

开机后拔着USB，进入视频实时拍摄画面；启用显示时，服务运行后左下角会出现小上传标记，不需要先录像。
程序先核对卡上视频并补传没有成功回执的文件，然后处理新增视频。首次耗时与卡上文件数量、Wi-Fi连接和FTP响应有关。

首次试用录一段约10–15秒XAVC S视频，停止后停在拍摄画面。上传时标记变成进度条，完成后回到标记。
最终检查FTP目录里出现非 `.part` 的完整MP4且能正常播放；不要只以图标判断成功。文件名可能是身份生成名，不一定保留相机的 `Cxxxx.MP4`。
本版主要实测XAVC S，不把AVCHD或其他录制格式列为已支持。

原文件留在SD卡；成功后写SD回执去重。失败会重试，退避最长约10分钟；休眠/关机时不会强行持续联网，正常唤醒后继续。
这里的重试**不是从上次字节偏移继续**，中途失败的 `.part` 可能从头重传。不要在程序运行时手工删回执或改临时文件。
服务器副本被手动删除后，已有SD成功回执不保证自动触发重新上传；需要补传时先反馈，不要格式化卡来“刷新”。

不需要常驻电脑、手机热点或NAS专用接收器。索引、缩略图和相册显示由NAS自己的应用处理。

## 6. 不成功时发什么

按[故障反馈模板](FEEDBACK.md)提供型号、固件、系统、包修订、界面提示和操作时间。
相机还能连接USB时，App“读取运行日志”或脚本 `diagnose` 可收集有限日志；它会切服务模式，不是完全无设备交互的操作。
不要发送FTP密码、机内backup目录、完整SD卡或内存转储。
