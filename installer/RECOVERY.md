# 恢复、停止显示与卸载

适用安装器：`0.1.0-preview.25`，载荷 `0.4.2-photos.5-preview`；恢复本安装器保存且校验通过的单槽应用备份。先选符合现状的一条，避免把“恢复上次安装”“卸载”和“恢复电脑USB驱动”混为一谈。

界面识别出已安装服务后，在主界面相机卡片显示「卸载相机服务」；先连接并读取状态即可使用，不需要重复安装。
恢复、读取运行日志及Windows驱动操作在右上角「更多」，相关操作范围不变。
Windows「卸载服务时恢复 Windows USB 驱动」在该菜单内默认勾选。

| 目的或现象 | 应做什么 | 完成后 |
| --- | --- | --- |
| 安装中断、更新失败，或撤销最近一次安装/配置 | 恢复上次安装 | 完全断电一次，检查恢复后的服务状态 |
| 不再使用上传器 | 卸载 | 完全断电；Windows可联动恢复驱动 |
| 仅停用自定义显示，保留上传 | 沿用配置并关闭显示后重新配置 | 完全断电；上传保留，不再出现常驻标记 |
| USB正常但没有标记/视频 | 先读取日志和检查网络 | 依据提示处理，不反复覆盖安装 |
| 黑屏且半按无效，USB也不可用 | 按下文电源恢复分支 | 恢复USB后先读取日志，再撤销或卸载 |

## 备份到底保存了什么

安装器只有**一个应用备份槽**，位于机内 `/setting/a7c-installer/backup`，不是整机固件备份，也不是SD备份。
每次安装、配置修改或卸载都会重新保存操作前的应用状态，覆盖这个槽；恢复本身不会先覆盖备份。
因此“恢复上次安装”恢复的是**最近一次操作前**的文件、配置和启用状态，不一定是最初的原厂状态或你心中的稳定版本。

- 第一次在干净相机上安装后恢复：移除当时不存在的应用文件，撤销这次安装。
- 更新或改FTP配置后恢复：还原更新前的程序与FTP配置。
- 卸载后再恢复：会把刚卸载的应用和旧FTP凭据装回来。
- 新执行一次“安装 / 更新配置”或“卸载”，可能覆盖你本来想恢复的那个备份。因此先恢复，再考虑下一步。

备份可能含明文FTP密码；目录权限限制为root访问，不应上传或分享。卸载会保留这份私有备份，
不能将“卸载完成”当作“机身上所有凭据已擦除”。若要转交相机，先在服务器撤销该专用账号；本版没有一键敏感备份清除功能。

## 安装中断或想撤销最近一次变更

1. 不再点击安装。若界面仍显示操作中，先等它返回结果；不要在写入期间拔USB。
2. 操作已结束后确认相机开机且能显示USB连接界面；无法连接时先看黑屏分支。
3. 用同一修订的完整安装包启动App；Mac提升管理员权限，Windows由安装器自动准备USB驱动。
4. 有条件时先“读取运行日志”留证据，然后点击“恢复上次安装”；脚本对应 `restore --yes`。
5. 工具会先校验备份。如果提示备份不存在、不完整或校验失败，停止，不手工改manifest、删锁或混用旧版二进制。
6. 明确显示恢复完成后，断开USB及外接电源，正常关机、等卡灯熄灭，取电池约30秒再装回开机。
7. 检查普通拍摄和回放。若恢复目标本来有上传器，再检查其是否按之前配置工作；不要求反复录像或休眠测试。

恢复也可能因USB中断而未完成。重新连上后仍使用“恢复上次安装”，不要用重新安装来绕过未完成标记。
工具保留其他软件的启动项，不恢复出厂设置，不改照片、视频或SD成功回执。

## 卸载

1. 确认相机可连USB，启动同一安装器。若提示上次事务未完成，先恢复。
2. 点击相机卡片的「卸载相机服务」，等待明确完成；脚本对应 `uninstall --yes`。卸载不需要填写FTP配置或连接FTP服务器。
3. 断开USB及外接电源，正常关机、等卡灯熄灭，取电池约30秒再装回开机，使旧RAM程序退出。
4. 若要重新安装，先完成上述完整断电；旧显示模块在同一次开机中不会重复初始化。正常使用时不应再有自定义服务标记或本程序的自动图片／视频上传。卡上媒体、成功回执及服务器视频仍保留。

卸载不删除上一代研究文件，不卸载NAS的FTP服务，只有Windows勾选联动恢复才恢复电脑驱动，也不清除私有回退备份。
本工具无法识别的未知程序不会被自动删掉；有旧研究版时先向维护者说明来源。

## 只关闭自定义显示

仅在**没有未完成安装事务**、且不需要保留当前回退槽时使用：App点击「连接相机」，保持已保存密码框为空以沿用密码，
取消「在相机上显示上传状态和进度」，点击「更新配置」；命令行是 `configure --reuse --no-display --yes`。
它仍会执行完整应用更新、FTP测试和备份，不是一个只改RAM的开关；成功后完全断电一次。
关闭后没有标记是预期结果，用FTP文件和日志确认上传。不能据此宣称历史黑屏已被治愈。

## 常驻标记消失、上传停止

开启显示时，上传和显示作为一个整体运行：如果某次上传中显示进度失败，程序会先把这个文件传完、写好卡上回执，然后整个服务停止，常驻标记也随之消失。这样显示坏了不会被悄悄忽略。

处理方法：正常关机，等卡灯熄灭，取出电池约 30 秒再装回开机（同一次开机里显示模块不会重新初始化）。开机连上 Wi‑Fi 后会自动继续上传，未完成的文件不会重复。若重启后仍反复出现，接 USB 用 App 的「读取运行日志」或命令行 `diagnose` 收集日志后反馈，不要反复重装。

## 黑屏且半按无法唤醒

普通熄屏先轻半按一次快门。若无效，且USB也不能恢复正常连接，不连续反复安装、刷固件或格式化SD卡。
先记下黑屏前在做什么、是否正在录像/上传、指示灯状态及时间；如果仍能通过USB读取日志，优先保存。

确认没有正在进行的官方固件更新后：拨到OFF，等卡灯停止，拔掉USB和其他外接电源，
取出电池约一分钟再装回开机。历史故障曾通过较长完全断电恢复；该方法不是所有故障的保证恢复路径。
若仍无反应或卡灯持续异常，不重复进行软件写入，联系维护者或索尼检修。

恢复连接后先读取日志，并优先恢复上次应用状态或卸载。断电会丢失RAM日志；不要把“取电池后好了”记为根因已修复。
本安装器拒绝处理固件更新设备 `054C:03E2`，没有刷机救砖能力。

## Windows驱动恢复

需要卸载相机程序时，先「卸载相机服务」，默认勾选「卸载相机服务后恢复本工具修改的 Windows USB 驱动」。
它先完成机内卸载及服务会话退出，再撤销电脑驱动；两阶段结果分别显示，电脑阶段失败时无需重复卸载相机服务。
相机应用备份与电脑驱动备份分别保存在相机与此Windows电脑，不能互相代替。

仅恢复USB照片导入可点击「恢复普通 USB 导入」，脚本为 `driver-restore --yes`；这不会删除相机内上传器。
恢复记录在 `%ProgramData%/A7CInstaller/drivers/state.json`，原第三方驱动也在该目录的对应子目录中。
不要删除此目录后再要求自动恢复。中断后使用同一电脑重试恢复。
工具先检查原驱动备份、自己生成的专用INF与已发布驱动包是否对应，再删除自己记录的驱动包并恢复原驱动。
恢复成功后重新插拔相机，检查资源管理器导入。未连接的设备会先恢复原驱动包，待下次连接由Windows重新绑定。

本工具未修改的手工Zadig驱动不会被自动卸载；如需清理这类旧驱动，按
[Zadig官方恢复说明](https://github.com/pbatard/libwdi/wiki/FAQ#help-zadig-replaced-the-driver-for-the-wrong-device-how-do-i-restore-it)
核对设备及其驱动包后单独处理，不抄用其他电脑的oem编号。
若驱动被第三方工具改过、同包仍绑定另一个设备实例或恢复记录损坏，工具保留记录并提示处理，未批量删除其他驱动。
libwdi生成的设备签名证书暂保留在Windows证书存储中；自动恢复目前只覆盖驱动绑定/驱动包。
Windows11已在本机身完成普通/服务驱动自动准备、模式切换、卸载联动恢复和原驱动核对；新设备以自身驱动日志为准。

## 脚本对应命令

简单入口：双击脚本包的「开始使用.command」（Mac）或「开始使用.cmd」（Windows），选5卸载、选6恢复。
下面的高级命令在解压后的**脚本包根目录**运行。macOS用 `sh` 避免依赖解压后的可执行权限：

```sh
sh start.sh detect
sh start.sh diagnose
# 以下三条按需求选择一条，不要顺序全部执行
sh start.sh restore --yes
sh start.sh uninstall --yes
sh start.sh configure --reuse --no-display --yes
```

Windows在管理员PowerShell中使用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\app\install.ps1 <动作> ...`，
例如 `powershell -NoProfile -ExecutionPolicy Bypass -File .\app\install.ps1 restore --yes`。
这是单次进程的脚本执行设置，不修改全局执行策略。组织策略仍阻止时停止并反馈。
不要把密码写进命令行；程序会通过隐藏输入读取。


## 删除电脑上的 App

机内服务和电脑App分开运行。不再使用自动上传时，先在App中执行「卸载相机服务」并按提示完全断电。
Mac随后关闭App，将「应用程序」中的「A7C 自动上传.app」移到废纸篓即可。
只删除电脑上的App不会卸载相机里的程序。Windows先按需要恢复驱动，再删除解压后的完整应用目录。
